# Enterprise DevOps Platform

This platform provisions a production-ready AWS and Kubernetes foundation for the existing microservices application.

## Scope
- AWS Organizations with management, security, log archive, networking, shared services, development, QA, pre-production and production accounts
- Terraform modules and Ansible automation for AWS and platform services
- EKS, ECR, ALB, API Gateway, Route53, CloudFront, WAF, Shield, ACM, RDS PostgreSQL, ElastiCache Redis, S3, OpenSearch, CloudWatch, Lambda, EventBridge, SNS and SQS
- Jenkins, Maven, SonarQube, Trivy, Nexus, Docker, Kubernetes, Helm, ArgoCD and GitOps
- Observability with Prometheus, Grafana, Fluent Bit, OpenSearch, Kibana, OpenTelemetry and Jaeger
